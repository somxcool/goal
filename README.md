### Installation
1. Run `python -m venv .venv` to create a virtual environment.
2. Run `pip install dearpygui` to install dearpygui.
3. `python goal.py` if you don't want to create an executable; `pip install pyinstaller` then `pyinstaller --onefile --windowed goal.py` if you do.
